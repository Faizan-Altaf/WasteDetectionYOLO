# Waste Detection System

AI-based waste object detection using YOLO and Streamlit.

## Waste classes
- Plastic Bottle
- Paper
- Can
- Plastic Bag

## Run locally
Install the dependencies:

    python -m pip install -r requirements.txt

Start the application:

    python -m streamlit run waste_app.py

## Model
The trained model is stored at `models/best.pt`.

## Disclaimer
Predictions depend on the training data and image quality. Results may be incorrect.
